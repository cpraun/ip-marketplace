# Output template — Strategic Analysis Report

This file is the single source of truth for the structure of the **Strategic Analysis Report** produced by the `oa-response-strategy-epc` skill. Produce the report in **exactly the order below**, using these headings.

Rules while filling it in:

- This is a working draft for the responsible European patent attorney — never a final response or filing.
- If a section does not apply to the case (for example, there is no clarity objection, so there is no Art. 84 recommendation), state that briefly and skip the body rather than inventing content to fill it.
- Replace every `[...]` placeholder. Do not leave bracketed guidance text in the delivered report.
- Section 5 expands to one numbered subsection per Art. 54/56 strategy — the top N routes sourced from the dependent claims plus the top M routes sourced from the description. Repeat the `### 5.[i]` block as many times as needed.
